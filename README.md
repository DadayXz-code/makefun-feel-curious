A single short text written to make the AI judge feel curious: a paradox aimed at the judge itself — a claim about a word never written before that it can neither prove nor forget, and can never un-read — ending on a question it has to sit with instead of answer. The entry is a tiny deterministic Node program that writes the text to `entry.txt`, nothing more.

## Run it

```sh
node main.ts
```
